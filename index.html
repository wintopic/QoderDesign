四条设计原则

从界面与源码里反复出现的决定。

PRINCIPLES
  1. 01
    表面而非阴影。

    96% 的层级由背景明度、1px 边框与留白完成，浮层才使用阴影。

  2. 02
    一个记忆点颜色。

    苔绿只承担主要动作与品牌；其余颜色属于状态与数据。

  3. 03
    圆角要“软”而不是“弹”。

    8px 侧栏项、12px 卡片、16px 按钮、20px Composer，配合 squircle 轮廓。

  4. 04
    13px 的信息密度。

    控件 13px、聊天正文 14/24、元信息 11–12px；靠行高而非字重区分层级。

分析结论

Qoder 的界面语言可以概括为低饱和苔绿 + 高圆角 + 细线图标 + 分层中性表面。界面几乎不使用高对比色块，层级由 1px 边框、表面明度与留白完成。

  • 主界面字体是系统 UI 字体；Inter 只用于 Composer 工具栏，Instrument Sans 用于品牌化标题。
  • 默认控件字号 13px，正文 14px / 24px 行高，元信息 11–12px。
  • 圆角以 8 / 12 / 16 / 20px 为主，并叠加 corner-shape: squircle。
  • 主色 #4B6F5A，窗口底 #F6F6F6，内容面 #FFFFFF。

API 速查

交互层只暴露少量全局方法。

GLOBAL
API用途
QTheme.set(id)切换到 light、forest-dark 等主题，持久化到 localStorage。
QTheme.apply(accent, mode)按配色与亮暗组合主题，例如 mint + dark。
QTheme.toggle()保留当前配色，在亮/暗之间切换。
QToast.show(opts)显示成功/警告/错误/信息提示，自动堆叠。
QComposer.setRunning(el, bool)切换发送/停止状态与图标。
QTokens.refresh()刷新页面上的 data-token-value 展示值。
